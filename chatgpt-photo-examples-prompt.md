# Request for Construction Site Photo Examples

I'm building a construction management app called BuildFlow that includes a photo manager for construction site documentation. I need you to provide a comprehensive list of realistic example photos that would be typical for a residential construction site.

## App Context:
- BuildFlow is a construction management app for residential building projects
- Features include: worker time tracking, manager dashboards, site management, materials tracking, and photo documentation
- The photo manager allows workers to capture and upload site photos with AI analysis for safety issues
- Photos are organized by site, plot number, and can include issues like "safety hazard", "quality concern", "damage", etc.

## What I Need:
Please provide a detailed list of 15-20 example construction photos with descriptions, organized by category. For each photo, include:
1. **Category** (e.g., Foundation, Framing, Roofing, Safety, Quality Issues, etc.)
2. **Specific Description** (what the photo shows)
3. **Suggested Tags/Issues** (if applicable - e.g., "safety hazard: no hard hat", "quality concern: uneven foundation")
4. **Plot/Stage Context** (e.g., "Plot 15 - Foundation stage", "Plot 7 - Framing complete")

## Categories to Cover:
- Foundation work (concrete pouring, rebar installation, footings)
- Framing (wall frames, roof trusses, structural elements)
- Roofing (tile installation, underlayment, flashing)
- Electrical rough-in
- Plumbing rough-in
- Drywall installation
- Site safety (PPE usage, scaffolding, hazard examples)
- Quality issues (defects, concerns, rework needed)
- Material delivery and storage
- Weather conditions affecting work
- Progress milestones
- Before/after comparisons

## Format:
Please format as a numbered list like this:

**1. Foundation - Rebar Grid Installation**
- Description: Workers installing rebar grid for foundation slab on Plot 12
- Stage: Foundation
- Possible Issues: None (good practice example)

**2. Safety Hazard - Missing PPE**
- Description: Worker on scaffolding at Plot 8 without harness
- Stage: Framing
- Issues: Safety hazard - fall protection missing

Make the descriptions realistic and varied to represent typical daily construction documentation.
